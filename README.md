# Knit-Vision

My graduation project in Control and Automation Engineering at Istanbul Technical University: computer vision for identifying knitting patterns and estimating stitch counts from images.

I created the dataset from samples I knitted myself and worked through image preparation, model training and evaluation. The project connects a hands-on craft with machine learning.

**Technologies:** Python, PyTorch, ResNet50, image processing, multi-output neural networks.

**My contribution:** knitted sample preparation, dataset creation, model development, training and evaluation.

This repository introduces the project. Training code, datasets and model artifacts are not included.

Developed by Okay Dedeoğlu.
